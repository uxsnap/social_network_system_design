# System Design социальной сети для курса по System Design

## Функциональные требования

### 1. Управление пользователям

Пользователь может:

1. Регистрироваться и входить в систему
2. Просматривать и редактировать собственный профиль (редактировать описание, фотографию)
3. Просматривать список собственных подписчиков
4. Отправлять пользователей в черный список
5. Выходить из своего профиля
6. Восстанавливать пароль через email (отправка кода или ссылки восстановления)

### 2. Управление постами

Пользователь может:

1. Создавать в системе пост
2. Привязывать к своему посту от 1 до 8\*n фотографий (пусть будет числое кратное 1 байту для оптимизации возможных манипуляций со списком)
3. Оставлять комментарий на посте - 140 символов изначально (лимит Twitterа), затем можно увеличить лимит при росте аудитории
4. Удалять собственные комментарии на постах
5. Удалять собственные посты
6. Архивировать собственные посты
7. Скрывать посты из собственной ленты
8. Привязывать локацию к посту
9. Ставить/убирать лайки с собственных постов
10. Просматривать и редактировать посты собственной ленты
11. Просматривать посты глобальной ленты всех пользователей системы
12. Просматривать детальную страницу поста (через модальное окно или отдельную страницу)
13. Ставить/убирать лайки с постов пользователей
14. Сортировать посты по популярности
15. Просматривать пользователей, которые лайкнули пост
16. Подписываться/отписываться от постов других пользователей

### 3. Система поиска

Пользователь может:

1. Просматривать карту с кластеризированными интересными местами (чтобы места не занимали все место на карте)
2. Искать места по гео-данным (страна, город, улица и тд)
3. Получать на карте интересные места
4. Фильтровать места по адресу
5. Фильтровать места по количеству лайков
6. Фильтровать места по
7. Искать пользователей по имени/username

### 4. Система нотификаций

Пользователь может:

1. Получать уведомления о собственных действиях (редактирование профиля, изменение кредов и тд)
2. Получать уведомления о действиях других пользователей (ваш пост лайкнули)
3. Отключать уведомления о действиях других пользователей (тонкая настройка на все действия)
